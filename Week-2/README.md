# FinTrust Week 2 Data Analytics

This project focused on analysing FinTrust's customer and transaction data to generate useful business insights and support management decision making.

## Work Completed

## 1. Data Quality Assessment

Profiled the customer and transaction datasets
Checked missing values, duplicates, data types, inconsistencies and unusual values
Identified potential transaction amount outliers
Verified the relationship between customer and transaction data
Documented the data quality findings

## 2. SQL Business Analysis

Used Jupyter Notebook to write and run SQL queries
Analysed customer segments, transaction activity, transaction values, transaction types and channels
Examined transaction status and risk review patterns
Documented the results and business interpretation for each question

## 3. Python Exploratory Data Analysis

Used Jupyter Notebook with Pandas, NumPy, Matplotlib and Seaborn
Explored customer behaviour, transaction values, channels and transaction trends
Analysed transaction success rates and risk review patterns
Created visualizations to support the findings

## 4. Power BI Dashboard

Built an initial management dashboard
Created KPIs for customers, transactions, transaction value, average transaction value, success rate and risk review rate
Added visuals for customer segments, transaction activity, channels, trends and risk patterns
Added filters for interactive analysis

## 5. Business Findings

Identified key patterns in customer and transaction behaviour
Highlighted differences in transaction performance across channels
Identified transaction types and conditions associated with higher risk review rates
Translated the analysis into business focused findings
