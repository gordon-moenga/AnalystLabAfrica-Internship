# Week 3 Data Analysis

## Overview

Week 3 focuses on taking the transaction analysis further through Advanced SQL and Exploratory Data Analysis using Python. The work builds on the earlier analysis by looking deeper into customer behaviour, transaction performance, risk, channels, segments, and trends.

The analysis uses both SQL and Python to find patterns in the data, test business findings, and produce evidence that can support management decisions.

## Tools Used

- SQL
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Power BI

## Advanced SQL Analysis

The Advanced SQL notebook uses deeper SQL techniques to answer business questions and investigate patterns in the transaction data.

The analysis includes:

- Aggregations using `SUM`, `COUNT`, `AVG`, and other functions
- `GROUP BY` analysis
- `CASE` statements
- `JOIN` operations
- Subqueries and CTEs
- Window functions
- Customer analysis
- Customer transaction frequency
- Customer value ranking
- Transaction success and failure analysis
- Risk review analysis
- Channel performance and transaction value
- Customer segment behaviour
- International versus domestic transactions
- High value transaction analysis
- Monthly transaction trends

The analysis also examines which areas contribute most to transaction value, transaction activity, unsuccessful transactions, and risk reviews.

## Exploratory Data Analysis

The Python EDA notebook extends the earlier analysis with deeper exploration and additional visualisations.

The EDA covers:

- Dataset structure and data types
- Data quality checks
- Missing values
- Descriptive statistics
- Transaction distributions
- Transaction value analysis
- Customer behaviour
- Customer frequency
- Customer segmentation
- Transaction success and failure
- Risk review patterns
- International and domestic transactions
- Channel comparisons
- Trend analysis
- Relationships between important variables
- Identification of unusual values and patterns

Additional visualisations were created to compare groups, examine trends, and support the findings from the SQL analysis.

## Key Business Measures

The analysis identified several important measures from the dataset:

- **12,000 transactions**
- **90.47% transaction success rate**
- **19.60% of transactions requiring risk review**
- **Approximately NGN 585.88 million total transaction value**
- **Approximately NGN 48.82 thousand average transaction value**
- **Approximately 1,500 customers**

These measures were used as a starting point for deeper analysis rather than being treated as final findings on their own.

## Business Findings

The analysis focused on understanding:

1. Transaction success and failure
2. Risk review activity
3. Customer activity and value
4. Transaction value and high value transactions
5. Channel performance
6. Customer segment behaviour
7. International versus domestic transactions
8. Changes in transaction performance over time

The findings were validated using evidence from the analysis before developing management recommendations.

## Validation and Recommendations

The final stage of the Week 3 analysis validates major business findings by comparing each finding with evidence from the data.

The validated findings are then used to develop management recommendations based on:

**Finding → Evidence → Business Implication → Recommended Action**

This ensures that the recommendations are based on the analysis rather than unsupported assumptions.

## Conclusion

Week 3 demonstrates how Advanced SQL and Python EDA can be used together to move from raw transaction data to deeper business analysis. The work combines technical SQL skills, statistical exploration, visual analysis, business validation, and evidence based recommendations.
